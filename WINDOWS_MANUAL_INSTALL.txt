AI COLLEGE — WINDOWS MANUAL INSTALL COMMANDS

Purpose
-------
This file provides a precise, copy-paste friendly list of commands and manual steps to install everything required on a Windows 10 machine when automatic package managers (e.g., winget) are not available. Follow the sections in order.

Notes
-----
- Prefer PowerShell (run as Administrator for system installs where noted).
- If you already have Python, Node, or Ollama installed, skip the corresponding install section but still verify versions as shown.
- Commands marked "Admin" require Administrator privileges. If you do not have Admin rights, install the tools manually via the links.

1) Check current PATH/tools
--------------------------
Open PowerShell (Win key → type "PowerShell" → Run as Administrator if necessary) and run:

# Check Python, Node, npm, curl
python --version
py -3 --version
node --version
npm --version
curl --version
ollama --version

2) Install Python 3 (3.8+)
---------------------------
Method A — Manual installer (recommended):
- Download the Windows installer from: https://www.python.org/downloads/windows/
- Run the installer and CHECK "Add Python 3.x to PATH" on the first page. Choose "Install Now".

Method B — Microsoft Store (no admin required):
- Open Microsoft Store and install "Python 3.x".

Verify in PowerShell:
python --version
py -3 --version

If the command is "python is not recognized", either re-open PowerShell or add Python to PATH manually.

3) Install pip & venv (usually included with modern Python)
----------------------------------------------------------
Confirm pip and venv work:

py -3 -m pip --version
py -3 -m venv --help

If pip missing: run
py -3 -m ensurepip --upgrade
py -3 -m pip install --upgrade pip

4) Install Node.js (LTS)
------------------------
Method A — Manual installer (recommended):
- Download Node.js LTS for Windows (x64) from https://nodejs.org/en/download/
- Run the installer (it installs npm too). Re-open PowerShell after install.

Method B — nvm-windows (no admin required after install):
- https://github.com/coreybutler/nvm-windows — use the installer and then `nvm install lts` and `nvm use lts`.

Verify:
node --version
npm --version

5) Install Git (optional but recommended)
----------------------------------------
- Download from https://git-scm.com/download/win and install.
- Verify: git --version

6) Install curl (if not present)
--------------------------------
- Windows 10 usually has curl. If not, install from https://curl.se/windows/ or use the Git for Windows installation which includes curl.

7) Install Ollama (manual)
---------------------------
Ollama provides a Windows installer. Manual steps:
- Visit: https://ollama.com/download
- Download the Windows installer and run it (Admin required). Follow prompts.
- After install, ensure `ollama` is on PATH by reopening PowerShell and running:
ollama --version

If you cannot run the installer, the script will not be able to pull models or serve; install Ollama manually and retry.

8) Prepare repository and .env
-----------------------------
Open PowerShell in the repository root (where you cloned the repo). If you copied the repo to the Windows machine, cd into it.

# If you don't already have .env, copy the example
if (-not (Test-Path .env) -and (Test-Path .env.example)) { Copy-Item .env.example .env }

Edit .env in a text editor if you want to change OLLAMA_MODEL or other settings.

9) Create Python virtual environment and install backend dependencies
--------------------------------------------------------------------
In PowerShell (repository root):

# Use Python launcher (py) for best compatibility
py -3 -m venv .\backend\.venv
# Activate the venv
.\backend\.venv\Scripts\Activate.ps1
# Upgrade pip and install requirements
python -m pip install --upgrade pip setuptools wheel
python -m pip install --upgrade -r .\backend\requirements.txt

If you cannot run Activate.ps1 due to ExecutionPolicy, run (Admin once):
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Then re-run the Activate command.

10) Install frontend Node dependencies
-------------------------------------
In PowerShell (repository root):
cd .\frontend
# If a package-lock.json is present (recommended):
npm ci
# Otherwise:
npm install
cd ..

11) Pull Ollama model (requires ollama)
--------------------------------------
Open PowerShell and run:
ollama list
# If your model is not in the list, pull it (reads model from .env by default):
# Replace MODEL with the desired model string if not using .env
ollama pull qwen2.5:1.5b

It may take time depending on network and model size.

12) Start Ollama serve (optional)
---------------------------------
In a PowerShell window (you may prefer to run in a background window or use a Windows Service utility):
ollama serve > .\ollama-serve.log 2>&1

13) Start the backend and frontend
----------------------------------
Backend (in one terminal)
# Activate venv if not already active
.\backend\.venv\Scripts\Activate.ps1
cd backend
uvicorn app.main:app --reload --port 8000

Frontend (in another terminal)
cd frontend
npm run dev

Open the frontend at http://localhost:5173 and backend docs at http://localhost:8000/docs

14) Troubleshooting & verification
----------------------------------
- Confirm Python: py -3 --version
- Confirm pip: py -3 -m pip --version
- Confirm Node/npm: node --version; npm --version
- Confirm Ollama: ollama --version; ollama list
- If uvicorn not found use: python -m pip install uvicorn[standard]
- If ports blocked, check Windows Firewall settings and allow inbound/outbound for Python/Node/Ollama.

15) Optional: Install Chocolatey (if you want a package manager)
----------------------------------------------------------------
Run in an elevated PowerShell (Admin):

Set-ExecutionPolicy Bypass -Scope Process -Force; 
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; 
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

Then you can use choco to install packages, e.g. choco install python nodejs-lts -y

16) Optional: Install Scoop (user-level package manager)
-------------------------------------------------------
Run in PowerShell (non-admin):
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex
scoop install python nodejs-lts

17) Final notes
---------------
- Manual installation on Windows is more error-prone than Linux automation. Follow the steps in order and verify each tool before proceeding to the next.
- If you want, after you confirm everything works on Windows I can produce a simple .bat file or PowerShell wrapper specific to your other system (without winget) that only runs the repository-local steps (venv creation, pip install, npm install, ollama pull) and assumes the user has installed Python/Node/Ollama manually.
